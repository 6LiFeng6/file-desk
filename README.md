# 文件工坊

[打开文件工坊在线版](https://file-desk-cn-1124.fizzyant20.chatgpt.site)

用于处理 Word、PDF 和图片的中文网页。转换、合并、压缩、OCR 和 AI 放大均在当前浏览器执行。用户文件不会发送到服务器。报名、报销和作业提交预设可以修改并保存在当前浏览器。

## 页面与照片整理

- 在 **PDF 缩略图编辑**中添加一个或多个 PDF。拖动缩略图或用箭头排序，可旋转、删除和插入空白页。
- 在 **PDF 加页码与统一 A4**中选择纸张和起始页码。统一纸张会重排页面内容，原有链接和交互控件可能变化。
- 通过 **按要求提交 → 手机拍照交材料**添加纸质材料照片，拖动四个角标拉正，排序后导出 A4 PDF，也可指定体积上限。
- **HEIC 转 JPG**支持批量转换。其他图片工具也能接收 HEIC / HEIF。**图片拼接**支持横排和竖排。
- **证件水印与隐私打码**支持批量水印、按页遮挡，并导出新副本。PDF 以重新绘制的图片页导出，原始文字层和附件不写入副本。
- **清除照片元数据**通过重新编码移除附加记录。**批量重命名**保留原文件数据，可以预览新名字并打包。

## 运行发行包

解压后，在目录里执行 **node serve.mjs**，然后打开 **http://127.0.0.1:4173**。也可以双击 **启动文件工坊.cmd**。需要安装 Node.js。发行包已包含构建产物、OCR 语言和 AI 模型。启动时无需下载依赖。

## 开发

建议使用 Node.js 22 或更新版本。依次执行 **npm ci**、**npm run dev**。运行 **npm test** 检查文件类型、尺寸和页码解析。运行 **npm run build** 生成静态站点 **dist/**，可部署到任何能提供 JavaScript 模块和静态资源的 HTTPS 主机。

## 操作范围

- Word 转 PDF 支持 DOCX。每页输出为图像，能保留常见文档结构，复杂 Word 排版请核对预览。输出 PDF 中的文字无法直接选取。
- PDF 转 Word 默认按原页摆放可编辑的文字框，图形和表格边线作为底图保留。可选图片版保留原页外观，也可提取文字后重新排版。无文字层的页面可以使用简体中文和英文 OCR，请核对识别结果。
- 压缩 PDF 优先尝试保留文字层。当目标体积要求较高时会转为图片页。结果会标明体积是否达标，以及文字能否继续选取。
- 图片支持 JPG、PNG、WebP、BMP 和 GIF 输入。动态 GIF 按静态图处理。AI 模式按 2 倍放大原图，支持原图最多 160 万像素。普通模式提供 2、3、4 倍。
- 每个输入文件最多 100 MB，每组最多 40 个、合计 300 MB。浏览器的可用内存会影响处理速度和实际可处理的尺寸。
- 处理引擎和模型的许可证随构建产物位于 **dist/local/**。
- HEIC 解码器 **dist/local/heic/heic-to.js** 是单独加载的 LGPL-3.0 模块。可从 [heic-to v1.6.7](https://github.com/hoppergee/heic-to/tree/v1.6.7) 获取源码和构建说明，以及所用 [libheif 源码](https://github.com/strukturag/libheif)。
